# Forest Notes

[English](#english) · [Українська](#українська)

## English

Forest Notes is a personal technology blog, working notebook, and knowledge
base. It contains practical notes, cheat sheets, configurations, and code
snippets from daily infrastructure and software work.

The site is built with Jekyll and published with GitHub Pages.

### Sources and disclaimer

Some notes include code, configurations, or solutions based on public sources,
including Stack Overflow, technical blogs, and official documentation. Links to
the original sources are included where available.

If you own content published here and want it removed or its attribution
updated, please open an [issue](https://github.com/iamzaychik/iamzaychik.github.io/issues).

## Українська

Forest Notes — це особистий технічний блог, робочий нотатник і база знань.
Тут зібрані практичні нотатки, шпаргалки, конфігурації та фрагменти коду з
повсякденної роботи з інфраструктурою і програмним забезпеченням.

Сайт створено на Jekyll і опубліковано за допомогою GitHub Pages.

### Джерела та застереження

Деякі нотатки містять код, конфігурації або рішення на основі відкритих
джерел, зокрема Stack Overflow, технічних блогів та офіційної документації.
За можливості у відповідних файлах наведено посилання на першоджерела.

Якщо ви є власником опублікованого тут контенту та хочете видалити його або
змінити атрибуцію, створіть [issue](https://github.com/iamzaychik/iamzaychik.github.io/issues).
