*Limit MikroTik download traffic and total session time with FreeRADIUS counters.*

*MikroTik-Xmit-Limit is the user's download limit. When reached, the session ends. A persistent limit allows the user to log in again and continue working, especially when cookies are enabled. The counter must therefore calculate and return the remaining value.*

Add a parameter to `/etc/freeradius/dictionary` if it does not exist:

```text
ATTRIBUTE       Mikrotik-Xmit-Limit          3001    integer
ATTRIBUTE       Download-Limit               3002    integer
```

Uncomment the counter include in `radiusd.conf`:

```text
$INCLUDE sql/mysql/counter.conf
```

Add the download counter:

```text
sqlcounter downloadcounter {
counter-name =  Download-Limit-Total
check-name = Download-Limit
reply-name = Mikrotik-Xmit-Limit
sqlmod-inst = sql
key = User-Name
reset = never
query = "SELECT ifnull(SUM(acctoutputoctets),0) FROM radacct WHERE username='%{ %k}'"
}
```

The important fields are:

- `check-name` is the parameter to add or find in the dictionaries.
- `reply-name` returns the remaining counter value under the response attribute.
- `query` calculates used traffic from the accounting database.
- A `NULL` result can cause FreeRADIUS to ignore the counter.

Enable the counter module in the `authorize` section.

Add the check attribute:

```sql
insert into radcheck (username,attribute,op,value) values ('test', 'Download-Limit', ':=', '1000000');
```

If SQL attributes are ignored, move the user to the file-based `users` database for troubleshooting:

```text
test       Cleartext-Password := "123", Download-Limit := 100000
```

If the attribute is missing from the dictionaries, FreeRADIUS reports an error such as `invalid octet string … for attribute` and fails to start.

*Count the user's total session time:*

```text
sqlcounter uptimecounter {
counter-name = Uptime-Total
check-name = Uptime-Limit
reply-name = Session-Timeout
sqlmod-inst = sql
key = User-Name
reset = never
query = "SELECT ifnull(sum(time_to_sec(timediff(acctstoptime,acctstarttime))),0) FROM radacct WHERE username like '%{ %k}'"
}
```

Enable the module in the `authorize` section.

The `Uptime-Limit` attribute exists in standard dictionaries and can be added if needed.

Session time is measured in seconds.
