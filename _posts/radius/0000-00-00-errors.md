*Interpret common RADIUS session termination reasons.*

| # | Reason | Description |
| --- | --- | --- |
| 1 | *User Request* | The user ended the session, for example through LCP Terminate or log out. |
| 2 | *Lost Carrier* | The DCD carrier signal was lost on the port. |
| 3 | *Lost Service* | The service is no longer available, for example after the host connection ended. |
| 4 | *Idle Timeout* | The permitted idle period expired. |
| 5 | *Session Timeout* | The maximum session duration was reached. |
| 6 | *Admin Reset* | An administrator reset the session or port. |
| 7 | *Admin Reboot* | The administrator stopped NAS user service, for example to reboot the NAS. |
| 8 | *Port Error* | The NAS detected a port error requiring session termination. |
| 9 | *NAS Error* | The NAS detected a non-port error requiring session termination. |
| 10 | *NAS Request* | The NAS ended the session for an unknown reason. |
| 11 | *NAS Reboot* | The NAS ended the session for an emergency reboot. |
| 12 | *Port Unneeded* | The NAS ended the session because resource usage was too low. |
| 13 | *Port Preempted* | The NAS ended the session to assign the port to a higher-priority user. |
| 14 | *Port Suspended* | The NAS ended the session to suspend a virtual session. |
| 15 | *Service Unavailable* | The NAS could not provide the requested service. |
| 16 | *Callback* | The NAS interrupted the session to establish a callback. |
| 17 | *User Error* | User data caused an error that ended the session. |
| 18 | *Host/User Request* | The host ended the session normally. |
