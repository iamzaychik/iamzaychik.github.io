*Common Cisco IOS configuration commands.*

* Create a user:
```bash
username admin secret 1234
enable secret admin
line vty 0 4
logging synchronous
login local
```

* Set the console password:
```bash
R1(config)#line console 0
R1(config-line)#password cisco
R1(config-line)#login
```

* Set the Telnet password:
```bash
R1(config)#line vty 0 4
R1(config-line)#password cisco
R1(config-line)#login
```

* Remove the console password:
```bash
router(config)#line console 0
router(config-line)#no login
router(config-line)#no password
```

* Remove the Secret password:
```bash
router(config)#no enable secret
```

* Check the Register parameter:
```bash
router#show version
```

* Configure the address and mask, then enable the interface administratively:
```bash
R1(config)#interface Serial0/0/0
R1(config-if)#ip address 192.168.2.1 255.255.255.0
```

* Disable the router interface administratively:
```bash
router(config)#int s0/0
router(config-if)#shutdown
```

* Enable the Serial interface:
```bash
router#configure terminal
router(config)#interface s0/0
router(config-if)#no shutdown
```

* Set the clock rate for the Serial interface:
```bash
router(config-if)#clock rate 64000
```

* Check the Serial interface:
```bash
router(config)#show interfaces s0/0
```

* Add a static entry to the routing table:
```bash
Router(config)#ip route 10.10.10.0 255.255.255.0 {ip-address | exit-interface }
```

* View the routing table:
```bash
R1#show ip route
```

* View the interfaces:
```bash
R1#show interfaces
```

* View the interfaces and their statistics as a table:
```bash
R1#show ip interface brief
```

* View neighboring devices:
```bash
Router#show cdp neighbors
Router#show cdp neighbors detail
```

* Disable CDP (Cisco Discovery Protocol) globally:
```bash
Router(config)#no cdp run
```

* Disable CDP (Cisco Discovery Protocol) on an interface:
```bash
Router(config-if)#no cdp enable
```

* Check the DTE/DCE status:
```bash
router#show controllers s0/0
```

* Save the configuration:
```bash
router#copy running-config startup-config
```

* Download a file, such as IOS, from a TFTP server:
```bash
R#copy tftp flash:
```

* Back up the startup configuration to TFTP:
```bash
router#copy startup-config tftp
```

* Save the running configuration:
```bash
router#write memory
router#copy run st
```

* Erase the NVRAM configuration:
```bash
router#write erase
```

* Check the NVRAM configuration:
```bash
router#show startup-config
```

* View the switch MAC address table:
```bash
show mac-address-table
```

* Add a MAC address statically to the switch table:
```bash
router#mac-address-table static MAC address vlan {1-4096, ALL} interface interface-id command
```

* Create a VLAN:
```bash
S1(config)#vlan 20
S1(config-vlan)#name students
```

* Create a VLAN management interface:
```bash
S1(config)#interface vlan 20
S1(config-if)#ip address 10.2.2.1 255.255.255.0
S1(config-if)#no shutdown
```

* Assign a port for VLAN access:
```bash
S1(config)#interface fa0/18
S1(config-if)#switchport mode access
S1(config-if)#switchport access vlan 20
```

* Assign a port to a Cisco Dynamic Trunking Protocol trunk:
```bash
S1(config)#interface fa0/18
S1(config-if)#switchport mode trunk
S1(config-if)#switchport mode dynamic auto
S1(config-if)#switchport mode dynamic desirable
S1(config-if)#switchport mode nonegotiate
```

* Specify the VLANs allowed through the trunk:
```bash
S1(config-if)#switchport trunk allowed vlan 18 (ranges or all are allowed)
```

* Switch from trunk mode back to access mode:
```bash
S1(config-if)#no switchport trunk allowed vlan
S1(config-if)#no switchport trunk native vlan
S1(config-if)#switchport mode access
```

* Allow native VLAN traffic through the trunk port:
```bash
S1(config)#interface fa0/18
S1(config-if)#switchport mode trunk
S1(config-if)#switchport trunk native vlan 18
S1#show interfaces fa0/18 switchport
```

* View VLAN statistics:
```bash
show vlan brief
show vlan id 20
show vlan name students
show vlan summary
```

* View switch port statistics:
```bash
show interfaces vlan 20
show interfaces fa0/18 switchport
```

* Assign the default gateway:
```bash
S1(config)#ip default gateway 1.2.3.4
```

* Enable a dynamic routing protocol:
```bash
R1(config)#router protocol (rip, eigrp, etc.)
R1(config-router)#network network_number [wildcard_mask]
R1(config-if)#bandwidth 64
```

* Disable dynamic routing on an interface:
```bash
R1(config-router)#passive-interface s 0/0/0
```
or

```bash
R1(config-router)#passive-interface default
```

* Disable dynamic routing on all interfaces, then enable it on selected interfaces:
```bash
R1(config-router)#no passive-interface s 0/0/0
```
