*Echo HTTP requests through a lightweight Docker Compose service.*

### Run the echo server

```yaml
services:
  echo:
    container_name: 'echo'
    image: 'mendhak/http-https-echo:23'
    restart: 'always'
    ports:
      - '80:8080'
```
