*Configure PPPoE routing and NAT on a DD-WRT router.*

1. Log in to the web UI at `192.168.1.1`, under `Setup -> Basic Setup -> Connection Type - PPPoE`.
2. Enter the username and password provided by your provider. Select `Save`:
![basic-setup](/assets/img/dd-wrt/basic-setup.png)

3. Open the `Status -> Sys-Info` tab and note the WAN MAC address:
![system-info](/assets/img/dd-wrt/system-info.jpg)

4. Open the `Administration->Commands` tab and enter:

```bash
ifconfig
```

5. Find the interface matching your WAN MAC and note its name, such as `vlan1`:
![wan-mac](/assets/img/dd-wrt/wan-mac.jpg)

6. Insert your local network parameters into the following commands:

```bash
ifconfig vlan1 down
ifconfig vlan1 your_local_ip netmask 255.255.252.0
ifconfig vlan1 up
route add -net 91.105.204.0 netmask 255.255.255.0 gw 10.x.x.5
```

7. Select `Save Startup`.

8. Forward NAT from the home network to the selected interface:

```bash
iptables -A FORWARD -s 192.168.1.0/24 -j ACCEPT
iptables -A FORWARD -d 192.168.1.0/24 -j ACCEPT
iptables -t nat -A POSTROUTING -o vlan1 -s 192.168.1.0/24 -j MASQUERADE
```

9. Press `Save Firewall`
10. Select `Management -> Reboot Router`.

*The router will take slightly longer than usual to boot.*
11. Configure Wireless according to your requirements.
