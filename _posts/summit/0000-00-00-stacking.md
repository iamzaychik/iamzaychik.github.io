**Setting up a new stack**
<ol>
   *Collect the ExOS release version from every node. All stack nodes must use the same version:
`show version images`
   *Check which ExOS partition (primary or secondary) each node boots from. All stack nodes must use the same partition:
`show switch`
   *Collect the licence level from every node and choose the level at which nodes with Master Capability will operate:
`show licenses`
   *Power off the nodes.
   *Connect the nodes with stacking cables.
   *Power on the nodes.
   *Log in through the console to the switch intended to become the master.
   *To verify the physical connection between nodes, run:
`show stacking`
   *The list must contain every stack device in the Disabled state and Master role.
   *Enable stacking on every node:
`enable stacking [node-address 00:00:00:00:00:00] (if no node is specified, stacking is enabled on all nodes)`
   *Set the stack MAC address to the master's MAC address:
`configure stacking mac-address`
   *Assign a slot number to each node:
`configure stacking node-address 00:00:00:00:00:00 slot-number X
`
   *Disable Master Capability on nodes that should not become master or take part in Backup elections:
`configure stacking node-address 00:00:00:00:00:00 master-capability off`
   *Configure the stacking priority on each node:
`configure stacking node-address 00:00:00:00:00:00 priority (10-100)`
   *Restart the stack:
`reboot stack-topology`
   *Log in to the master and check the stack status:
`show stacking
show stacking configuration`
   *All nodes must be visible in the stack.
   *All nodes must be in the active state.
   *After roles are assigned, the stack should contain one master, one backup (if present), and a group of standby nodes.
   *Confirm that the intended switch became the master.
   *Configure the management IP network in the Mgmt VLAN:
`configure vlan Mgmt ipaddress A.B.C.D./24`
   *Configure the virtual modular switch represented by the stack as required, including VLANs, IP subnets, trunk groups, and routing.
   *Save the configuration:
`save configuration primary`
</ol>

-----

**Додаємо новий модуль в стек:**
1. Перевіряємо, що новий модуль має таку ж прошивку, як і весь стек:
`show version images`
2. Якщо все добре, то налаштовуємо стек:
`enable stacking node-address 00:00:00:00:00:00 (від  easy-setup потрібно відмовитися)
configure stacking node-address 00:00:00:00:00:00 slot-number X
configure stacking node-address 00:00:00:00:00:00 master-capability off
configure stacking node-address 00:00:00:00:00:00 priority 10-100
synchronize stacking node-address 00:00:00:00:00:00
reboot node-address 00:00:00:00:00:00`
3. Перевіряємо стан стека:
`show stacking
show stacking configuration`
