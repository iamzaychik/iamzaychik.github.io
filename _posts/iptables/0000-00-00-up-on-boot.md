---

*Restore iptables rules automatically during network startup.*

- Create file:

```bash
$ cat /etc/network/if-pre-up.d/iptables
#!/bin/bash
/sbin/iptables-restore /etc/iptables.rules
```

- Add exec permissions:

```bash
$ chmod +x /etc/network/if-pre-up.d/iptables
```
